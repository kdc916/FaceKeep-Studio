# FaceKeep Studio v0.5.0

선택한 얼굴만 남기고 다른 얼굴을 이모티콘·모자이크·블러로 가리는 브라우저 사진 편집기.

## v0.5.0 — 블러·모자이크 바깥 소프트 경계

- 모자이크·블러 선택 시 **경계 소프트 확장** 슬라이더 표시 (0~60%, 기본 22%).
- **얼굴 커버 내부는 완전히 가리고, 바깥쪽으로만** 원본과 부드럽게 이어지는 Feather 마스크 처리.
- 타원형·사각형 형태 모두 지원하며, 소프트 0%일 때 기존 하드 경계 사용.
- 미리보기는 최대 2048px 소스를 별도로 사용해 고해상도 사진 조작 부담 감소.
- 소프트 조절 시 모자이크 블록 크기가 함께 변하지 않도록 개선.
- GitHub Pages와 로컬 HTML에서 동일한 단일 파일 사용. 사진은 서버 업로드하지 않음.

**사용:** 사진을 불러온 다음 모자이크 또는 블러를 선택하고, `경계 소프트 확장`을 조절하세요. 공유하기 전에 모든 얼굴이 잘 가려졌는지 확인하세요.

## 사용하기

1. 압축을 풀어 `index.html`을 Chrome / Edge / 모바일 웹 브라우저로 실행합니다.
2. JPG·PNG·WEBP·HEIC/HEIF 사진을 선택합니다.
3. **자동 얼굴 감지**가 실행됩니다. 빠른 감지 결과가 없거나 고해상도에서 얼굴 수가 적으면 자동으로 더 촘촘하게 다시 찾습니다.
4. **원본을 유지할 얼굴만 누릅니다.** 처음 감지된 얼굴은 기본적으로 가려진 상태입니다.
5. 누락된 얼굴은 미리보기의 **＋ 영역 추가**로 얼굴 주변에 사각형을 그린 후 조정합니다.
6. 이모티콘/사용자 PNG 스티커/모자이크/블러를 설정하고 결과물을 PNG/JPG/WEBP로 저장합니다.

## v0.4.0 변경점

- 내장된 HAAR 얼굴 탐지 모델을 정면 기본 + 정면 보조 + 좌우 측면으로 확장 (외부 서버·모델 로딩 불필요).
- 고해상도 사진에서 작게 나오는 얼굴을 위해 **겹치는 이미지 타일** 정밀 탐지 추가.
- 일반 탐지가 0명 또는 고해상도 사진에서 인원이 매우 적으면 자동으로 정밀 재분석하도록 변경.
- 보조 분류기의 낮은 신뢰도 검색 결과 필터링: 배경·옷을 얼굴로 오탐하는 경우 감소.
- 얼굴 진단 정보 및 복사 버튼 추가: 브라우저·원본 크기·탐지 단계·시간·오류 확인.
- v0.3.0의 HEIC/HEIF 로딩 및 기존 편집·저장 기능 유지.

## HEIC/HEIF 참고

브라우저에서 바로 디코딩할 수 없는 HEIC 사진은 `heic-to@1.6.6` IIFE 스크립트를 CDN에서 받아 변환합니다. **이 경우 최초 변환 시 인터넷 연결이 필요합니다.** 사진 파일 자체는 서버에 업로드하지 않습니다. 외부 스크립트 다운로드나 디코딩이 실패하면 화면에서 오류 이유를 확인할 수 있습니다.

## 정확도 관련 주의

- Haar 기반 엔진은 최신 AI 얼굴 인식 모델 수준의 정확도를 제공하지 않습니다. 옆얼굴, 부분 가림, 역광, 아주 작은 얼굴은 놓칠 수 있습니다.
- 정밀 모드는 모바일에서 여러 초에서 수십 초까지 소요될 수 있으며, 일부 오탐이 발생할 수 있습니다.
- **공유 전 모든 인물 얼굴이 확실히 가려졌는지 확인**하고 누락 시 수동 영역 추가를 사용하세요.
- 사용자가 직접 선택한 얼굴만 원본으로 남기며, **인물 자동 식별/동일인물 추적** 기능은 없습니다.

## 오류 확인

1. 사진 미리보기와 크기(예: 4032 × 3024px)가 표시되는지 먼저 확인하세요.
2. 사진이 보이는데 `0명`이면 **작은 얼굴·측면 정밀 탐지** 버튼으로 다시 검색하세요.
3. 오류가 계속되면 **얼굴 감지 진단 정보**를 펼쳐 내용을 복사한 뒤 전달해 주세요. 사진 자체를 보내지 않아도 원인 진단에 도움이 됩니다.
